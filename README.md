# Miratorg Landing

## Products page

Страница `products.html` берёт данные товаров из файла:

```text
assets/json/products.json
```

Логика рендера и фильтрации находится в:

```text
assets/js/modules/products.js
```

### Структура `products.json`

Файл должен быть валидным JSON-массивом. Каждый товар — отдельный объект:

```json
{
  "id": "1010013416",
  "name": "Колбаски «Баварские» Tender Pork охл.",
  "weight": "1,44 кг.",
  "category": ["Свинина"],
  "segment": ["КУПАТЫ"]
}
```

### Поля товара

`id`

Артикул товара. Обязательное поле. Должен быть строкой, даже если состоит только из цифр.

```json
"id": "1010013416"
```

Этот же `id` используется для поиска картинки товара.

`name`

Название товара, которое выводится в карточке.

`weight`

Вес товара, который выводится под названием.

Формат:

```json
"weight": "1,44 кг."
```

Если вес меньше 1 кг, пишем в граммах:

```json
"weight": "300 гр."
```

`category`

Массив категорий товара. Даже если категория одна, всё равно используем массив.

```json
"category": ["Говядина"]
```

Если товар относится к нескольким категориям, добавляем несколько значений:

```json
"category": ["Ягнятина", "Баранина"]
```

Категории на странице собираются автоматически из этого поля. Порядок категорий соответствует первому появлению в JSON.

`segment`

Массив сегментов товара. Даже если сегмент один, используем массив.

```json
"segment": ["СТЕЙКИ"]
```

Если в исходных данных сегмент явно разделён через `/`, это несколько сегментов:

```json
"segment": ["КОТЛЕТЫ", "БУРГЕРЫ"]
```

Сегменты на странице собираются автоматически из товаров выбранной категории. Для категории `Все` собираются сегменты всех товаров. Сегменты сортируются по алфавиту.

### Картинки товаров

Картинки лежат в папке:

```text
assets/img/products/
```

Имя картинки должно точно совпадать с `id` товара:

```text
assets/img/products/1010013416.webp
```

Формат картинок: только `.webp`.

Если для товара нет изображения, используется заглушка:

```text
assets/img/products/empty.webp
```

Можно также создать копию заглушки с именем артикула:

```text
assets/img/products/1010028791.webp
```

### Фильтрация и URL

Фильтры страницы хранятся в адресной строке:

```text
products.html?category=Говядина&segment=СТЕЙКИ&page=2
```

Параметры:

- `category` — выбранная категория;
- `segment` — выбранный сегмент;
- `page` — текущая страница пагинации.

Служебное значение `all` означает `Все`:

```text
products.html?category=all&segment=all&page=1
```

Если URL чистый, страница работает как `Все / Все / страница 1`.

При смене категории сегмент сбрасывается на `all`, а страница — на `1`.

### Пагинация

Количество товаров на странице задаётся в `assets/js/modules/products.js`:

```js
const PRODUCTS_PER_PAGE = 20;
```

Числовых кнопок пагинации показывается не больше 6:

```js
const MAX_PAGINATION_BUTTONS = 6;
```

### Важно при редактировании

- После изменения `products.json` проверьте, что JSON валидный.
- Не удаляйте обязательные поля `id`, `name`, `weight`, `category`, `segment`.
- `category` и `segment` всегда должны быть массивами.
- Для нового товара добавьте картинку `assets/img/products/<id>.webp` или убедитесь, что есть `empty.webp`.
- Не используйте обычные кавычки `"` внутри `name`; заменяйте их на `«»`, чтобы не ломать JSON.
